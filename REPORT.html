01

專案概述

🎯 目的

將 OpenCode AI 程式碼助理與 LINE Messaging API 整合，讓使用者透過 LINE 官方帳號以聊天方式與 AI 互動。

👥 適用對象

需要在手機上隨時使用 AI 輔助的開發者、想在 LINE 群組中整合 AI 助理的團隊、對 AI 聊天機器人有興趣的使用者。

✨ 主要功能

功能說明
多輪對話支援連續對話，保留上下文記憶
模型切換可自由切換不同 AI 模型（Anthropic / OpenAI / Google 等）
群組聊天支援 LINE 群組，AI 自動判斷是否回應
免費方案內建 Big Pickle 模型，零成本即可使用
使用者記憶自動記錄使用者名稱與對話歷史

  1. 設定環境變數

  2. 啟動 Docker 服務

  4. 設定 LINE Webhook

10

常見問題

❓ 收不到 Bot 回覆？

1. 檢查 ngrok 日誌 docker logs opencode-line-ngrok
2. 確認 LINE Webhook 設定正確
3. 檢查 Bot 日誌 docker logs opencode-line-bot

❓ ngrok URL 變了？

每次重啟 URL 都會變。建議註冊 ngrok 帳號並設定 Authtoken，網址就會固定。變更後需更新 LINE Webhook。

❓ Docker 無法啟動？

docker info 檢查 Docker 狀態。
docker compose down; docker compose up -d --build 重新啟動。

❓ 重啟後對話不見？

Session 儲存在記憶體中，重啟後會自動建立新 session，傳送訊息即可繼續使用。
