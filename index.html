09

常見問題

FAQ

❓ 收不到 Bot 回覆？

1. 檢查 ngrok：docker logs opencode-line-ngrok
2. 確認 LINE Webhook URL 是否正確
3. 檢查 Bot 日誌是否有錯誤
4. 確認 .env 金鑰正確

❓ ngrok URL 變了？

每次 ngrok 重啟 URL 都會變。建議註冊 ngrok 帳號並設定 Authtoken，網址就會固定。變更後需更新 LINE Webhook。

❓ Docker 無法啟動？

docker info 檢查 Docker 狀態。
docker compose down; docker compose up -d --build 重新啟動。

❓ 重啟後對話不見？

Session 儲存在記憶體中，重啟後會自動建立新 session，傳送訊息即可繼續使用，不需任何設定。
